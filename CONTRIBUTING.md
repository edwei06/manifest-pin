# Contributing

Use Python 3.10 or newer. Create a virtual environment, then run
`python -m pip install -e .` and `python -m unittest discover -s tests -v`.

Open an issue with a small reproducible example before proposing a large change.
Use synthetic data. Never attach credentials, private exports, or personal data.
Bug fixes should include a regression test demonstrating the user-visible issue.
Keep runtime dependencies at zero unless a concrete requirement justifies one.

Contributions are accepted under the repository's MIT license.
